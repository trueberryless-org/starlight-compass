  <Card title="Feedback while you write" icon="pencil">

  </Card>
  <Card title="Audits in CI" icon="approve-check">

  </Card>
  <Card title="Diátaxis built in" icon="seti:folder">

  </Card>
  <Card title="Provider-agnostic" icon="puzzle">
    Starts with [TypeSafe's Jev](/reference/providers/#typesafe), and is built
    around [providers and rules](/concepts/how-it-works/#providers-and-rules)
    you can swap or write yourself.
  </Card>
